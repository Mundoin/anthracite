# management-aaa-depth-005

This parser-prep pack focuses on management-plane and AAA depth across
the vendors already represented in `parser-lab/`.

## Scope

- SSH, SNMP, NTP, logging, and telnet/console-style hints
- Local users, user groups, and AAA-style blocks where natural
- Management access controls and service enablement hints
- Note-only ACL / NAT / QoS / security / routing markers

## Status

- Parser-prep only
- Synthetic and sanitized
- Ready for OCC review, not production-integrated

## Vendors included

- Cisco IOS-XE
- Cisco IOS-XR
- Huawei VRP
- MikroTik RouterOS
- Fortinet FortiOS
- Nokia SR OS
