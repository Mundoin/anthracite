# ospf-bgp-basics-004 edge cases

- Cisco IOS-XE can express OSPF via network statements and interface
  adjacency hints.
- IOS-XR OSPF/BGP nesting is more context-heavy than IOS-XE.
- Huawei keeps OSPF and BGP in separate protocol blocks.
- SR OS routing syntax is service-oriented and may nest peers differently
  from Cisco.
- Note-only ACL / NAT / QoS / AAA / security / routing lines should stay
  conservative.
