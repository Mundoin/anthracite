# ospf-bgp-basics-004

This parser-prep pack focuses on basic OSPF and BGP syntax across the
vendors already represented in `parser-lab/`.

## Scope

- OSPF and BGP top-level basics
- Router IDs, neighbors, areas, and simple network statements
- Basic interface adjacency hints where natural
- Note-only ACL / NAT / QoS / AAA / security / routing markers

## Status

- Parser-prep only
- Synthetic and sanitized
- Ready for OCC review, not production-integrated

## Vendors included

- Cisco IOS-XE
- Cisco IOS-XR
- Huawei VRP
- Nokia SR OS
