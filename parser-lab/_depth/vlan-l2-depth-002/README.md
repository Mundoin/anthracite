# vlan-l2-depth-002

This parser-prep pack focuses on VLAN and Layer 2 switching depth across
the vendors already represented in `parser-lab/`.

## Scope

- VLAN database or VLAN object coverage where native
- Access, trunk, native VLAN, and voice VLAN forms
- VLAN ranges and tagged/untagged membership
- SVI / routed bridge termination where natural
- L2 transport or service-based VLAN/L2 forms where natural
- Note-only management/security markers

## Status

- Parser-prep only
- Synthetic and sanitized
- Ready for OCC review, not production-integrated

## Vendors included

- Cisco IOS-XE
- Cisco IOS-XR
- Huawei VRP
- MikroTik RouterOS
- Fortinet FortiOS
- Nokia SR OS
