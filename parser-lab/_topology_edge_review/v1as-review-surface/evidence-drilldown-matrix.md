# Evidence Drilldown Matrix

| Selected edge | Visible evidence | What the inspector shows |
| --- | --- | --- |
| accepted | accepted evidence | Source kind, source label, node pair, interfaces, and accepted status. |
| duplicate-collapsed | duplicate evidence plus one projected edge | Both records stay visible, but the current edge stays singular. |
| merged | multiple labels and notes | The edge stays one row; evidence remains multi-source. |
| appended | multiple sources | Added evidence is explicit; duplicates are not hidden. |
| mixed | accepted and rejected | Side-by-side review stays honest. |
| conflicting | conflicting_remote_endpoint | Conflict remains unresolved and visible. |
| stale | stale_evidence | Stale evidence is labelled and not promoted. |
