# Stale neighbour edge cases

- A stale report can still have a full remote system name.
- Age thresholds may vary by source and should stay in OCC policy.
- A stale report should not overwrite a fresher one for the same pair.
- A stale report may still be useful as a hint for later correlation.
- Stale evidence should preserve the raw output and the reason it was held or
  rejected.
